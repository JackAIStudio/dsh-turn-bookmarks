# dsh-turn-bookmarks (DSH 会话轮次收藏与对话内检索插件)

DSH Web GUI 原生 Turn Rail（轮次导航轨）深度赋能插件：**100% 融入官方原生轨道**，告别冗余并排的第二条尺子。

## 核心特性

- **清晰轮次标明（SSOT 单一事实源）**：基于官方原生刻度无障碍 `aria-label` 精准解析 `turn` 轮次编号，无论长对话虚拟化如何滚动，绝对不发生任何错位！
- **悬停卡片原生注入**：官方预览卡悬停时，自动注入「第 N 轮」徽章、一键收藏（⭐）及一键复制（📋）问答正文，不篡改官方原生定位与渲染流程。
- **量尺金色微光高亮**：收藏的轮次在右侧官方量尺上呈现醒目的金色加宽刻度条与粒子光晕，一眼纵览整场对话关键节点。
- **全会话内即时检索**：
  - 点击右上角搜索图标展开搜索栏（纯鼠标操作，**不占用任何全局快捷键**，不干扰正文输入；面板内点 `×` 收起）；
  - 实时统计匹配轮次（如 `1/4 轮`），并在量尺上高亮所有匹配刻度（亮蓝/青色微光）；
  - 在搜索框内支持 `Enter` / `Shift+Enter` 或 `▲` / `▼` 按钮在匹配轮次间顺畅跳转（仅在搜索框聚焦时生效，属局部按键，不劫持全局键盘）；
  - 跳转时触发官方原生 `click` 导航，自动支持「加载更早」历史回溯，并对目标消息气泡做视觉聚焦微光提示。
- **双轨书签导航（双轨架构）**：右侧官方原生轨保留全场轮次宏观总览，收藏轮次呈现琥珀金高亮；左侧另设**专属书签轨**，仅列出已收藏轮次（`★ T1` / `★ T2` 紧凑列），点击落点与原生轨完全分离，**彻底杜绝误点**。
- **跨会话持久化**：本地 `localStorage` + 后端 JSON 存储双重持久化，按 `sessionId` 严格隔离，数据永不丢失。
- **原生明暗主题自适应**：无缝跟随 DSH Web 浅色与深色模式。
